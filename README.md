# D3: Data-Driven Documents

> **This is a maintained fork of [d3/d3][upstream], published as
> [`@unabandoned/d3`][pkg].** Upstream's last release was 7.9.0 (March 2024).
> The API is unchanged; what differs is the packaging. The package ships
> self-contained bundles (`dist/d3.mjs`, `dist/d3.cjs`, and the `dist/d3.js` /
> `dist/d3.min.js` browser globals) with **no runtime dependencies**: the thirty
> `d3-*` modules are inlined at build time and kept current by Renovate. To use
> it under its usual name: `"d3": "npm:@unabandoned/d3@^7"`. See
> [.unabandoned.yml](.unabandoned.yml).

[upstream]: https://github.com/d3/d3
[pkg]: https://www.npmjs.com/package/@unabandoned/d3

**D3** (or **D3.js**) is a free, open-source JavaScript library for visualizing data. Its low-level approach built on web standards offers unparalleled flexibility in authoring dynamic, data-driven graphics. For more than a decade D3 has powered groundbreaking and award-winning visualizations, become a foundational building block of higher-level chart libraries, and fostered a vibrant community of data practitioners around the world.
